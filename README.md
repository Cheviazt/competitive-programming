# Competitive Programming

This is my competitive programming journey.

## Structure

```
atcoder/        AtCoder (dp-contest, ...)
codeforces/
  problemset/   Problemset solutions, grouped by rating (800, 900, ...)
  contests/     Live contest solutions, one folder per round
cses/           CSES Problem Set, grouped by section
leetcode/       LeetCode, prefixed with the problem number
spoj/           SPOJ
tlx/            TLX (OSN, TOC, TROC, Gemastik, topic practice, ...)
hackerrank/     HackerRank (CodeX, BCC bank soal, certification, ...)
bcc/            BCC: oprec, freepass, intern, warmup, bank soal
contests/       Other contests (Compfest, FindIT, GCW, ...)
learning/       Algorithm / data structure notes and practice
misc/           Solutions whose source problem is unknown
templates/      Starting template for new solutions
tools/          Helper programs (testcase generator, ...)
docs/           Reference documents
```

## Naming conventions

- Folders and files use `lowercase-kebab-case`, no spaces.
- Codeforces problemset: `<contestId><index>.cpp`, e.g. `1941B.cpp`.
- Contest problems: the problem letter, optionally followed by its name, e.g. `a.cpp`, `b-alternating-string.cpp`.
- LeetCode: `<4-digit number>-<title>.cpp`, e.g. `0070-climbing-stairs.cpp`.
- Alternative solutions for the same problem get a suffix: `-dp`, `-greedy`, `-bottomup`, `-v2`.
- Java files use `PascalCase.java`, since the file name must match the public class.
